# 演奏オフ募集データベース（ensouoff-db）
　本サービスは、１日限りの「演奏オフ会」の募集・応募ができるサイトです。インターネット上に散らばる情報の一元化と、演奏オフ文化の認知度向上を目的として制作しました。コロナ禍を経て減少してしまった演奏の機会を再び増やすための一つの手段として、多くの方に利用していただけたら嬉しいです。

　同時に、未経験業界への転職を目的とした、知識・スキルのアウトプット（ポートフォリオ）としての役割もあります。学習・制作の初期から現在まで、特に具体的な分野や職種は決めず、自分にできることから進めてまいりました。使用している言語や技術、この成果物自体が、提出先の企業様の取り扱う業務内容やプロダクトと大きく乖離しているかもしれません。<br>
　ですが、就業後どのような技術・言語を使うことになっても、成果物を一から完成させるために必要な粘り強さや向き合う姿勢などは、共通して必ず必要になるものであると考えています。
 
　また、当サービスを制作するにあたり、chatGPTに伴走していただきました。実際に手を動かしてコードを書くことで、インプット中心の学習では身につかなった技術を習得できたと感じ、簡単なエラーの解消や、コードの修正がすらすらとできるようになったことは、自分の自信につながりました。<br>
 　至らないところも多々あるかと思いますが、どうぞよろしくお願いいたします。

## 「演奏オフ」とは
　楽器を演奏する人々が、楽団等の団体に所属することなく、臨時にメンバーを集めて行う演奏会です。特にしっかりとした定義はありませんが、ジャンルを超えたさまざまなスタイルで行う演奏会も開かれています。<br>
　定期的な集合練習を伴わないものもあり、その日の予定を開けさえすれば誰でも参加でき、多くの人と交流できることが魅力です。<br>

## 操作フロー（演奏会を登録する）
1. トップページより、メインメニューの「演奏会を企画する」をクリック。
2. 必要事項を入力し、「確認画面に進む」をクリック。
3. 入力内容を確認後、修正箇所があれば「戻って修正する」を選択。「送信する」をクリックすると登録完了となる。

---

## 操作フロー（募集中の演奏会を確認する）
1. トップページよりメインメニューの「演奏会をさがす」をクリック。
2. 募集中の演奏会の一覧が表示される。各行の右端「詳細」より内容を確認できる。
3. また、トップページの「新着の募集」には、登録演奏会の情報を新しい順に２つピックアップして表示しているため、ここからでも詳細に飛ぶことができる。

## 開発の経緯
　制作を決めた当時、動画学習サイトでHTMLとCSS、JavaScriptの基礎を学び、同時進行で応用情報技術者の試験勉強をしていました。<br>
　いくつか成果物のアイディアがあったのですが、現時点で学んでいた言語・知識でおおよそ対応可能な「Webサービス」に焦点を当て、一つ成果物を完成させることを目標にしました。

　制作にあたっては、chatGPTに伴走してもらいながらの挑戦でした。始める前は、AIがすべてコードを書いてしまうならポートフォリオを作成してもあまり意味が無いかと思っていましたが、実際は全く違いました。<br>
　chatGPTのナビゲーションのおかげでモチベーションの維持ができたこと、エラーの解決法やコードの意味を丁寧に教えてもらえたことは、非常に良かったと思っています。<br>
　逆に、chatGPTの書いたコードそのままではname属性等の整合性が全く取れず、想定以上に自分で手直しする必要があったことは大変な苦労でした。しかし、不完全だからこそ解決するための過程が非常に勉強になり、少しずつですがスキルとして身についたと感じています。時間をかけた箇所ほど、解決した時の達成感を強く感じました。<br>
　chatGPTに「やらせる」のではなく「教えてもらう」こと、完成に向けて導いてもらうような使い方を徹底していました。

 　また、基本情報技術者試験や応用情報技術者試験で学んでいた内容を実際に活用することで、より深い理解に繋がりました。<br>
 　今回の成功体験を糧に、引き続き研鑽していきたいです。
